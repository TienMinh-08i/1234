# Source provenance

This package is a local, independent snapshot of preparation code from the user's workspace. `UPSTREAM_SNAPSHOT.json` records its origins and adaptations. No new license is asserted for that workspace code. Third-party libraries and the Marshmallow checkout are installed or obtained separately and retain their own licenses.

The archive does not contain datasets, benchmark results, model credentials, the Marshmallow checkout, virtual environments or third-party dependency source trees.
